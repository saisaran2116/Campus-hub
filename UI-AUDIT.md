# CampusHub UI and UX audit

| Screen | What changed |
|---|---|
| Homepage and navigation | Real campus photography, a shorter path to event discovery, and photo cards for upcoming events. Navigation wraps below the brand and account controls on narrow screens. |
| Catalogue and event details | Upcoming events are the default, with All dates available for past listings. Cards link to a bookmarkable event page with the date, location, registration, and schedule actions in one place. |
| Saved schedule | Event cards and detail pages share the same save action. Failed requests display an error. Schedule overlaps open a keyboard-accessible dialog with an explicit choice. |
| Sign-in and registration | Consistent form styling and clearer primary actions. A password sign-in started from a save link returns to the event. |
| Event creation, drafts and event finder | Forms and actions use the same spacing, contrast and button styles. Poster uploads and submitted image URLs are retained. |
| Organizer and manager dashboards | Submitted artwork has a photo fallback. The review queue reports loading and decision failures and offers a retry for failed requests. |
| Media | Removed the bundled illustration. Older records that point to it display a photograph. Existing uploaded posters and stock photos are retained. |
